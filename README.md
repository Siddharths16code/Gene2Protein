# 🧬 Gene2Protein

**DNA Analysis | Mutation Simulator | Effect Classification**

Gene2Protein is an educational bioinformatics web application built with Python and Streamlit. It helps users explore DNA sequences, protein translation, mutations, reading frames, and potential open reading frames.

## Features

- DNA sequence validation and GC content analysis
- DNA to mRNA transcription and protein translation
- Interactive mutation simulator
- Mutation effect classification
- Codon and amino acid comparison
- Six reading frame translation
- Open Reading Frame (ORF) detection and visualization
- Interactive Plotly visualizations
- Downloadable analysis report

## Tech Stack

- Python
- Streamlit
- Biopython
- Pandas
- Plotly

## Run Locally

1. Clone this repository.
2. Create and activate a Python virtual environment.
3. Install dependencies:

   `pip install -r requirements.txt`

4. Start the application:

   `streamlit run app.py`

## Disclaimer

This application is intended for educational and exploratory purposes only. It does not provide clinical or medical interpretations.
